Создание криптовалюты с использованием Simple-Web3-Php

Этот HTML-документ представляет собой руководство по созданию простой криптовалюты (токена ERC-20) на блокчейне Ethereum с помощью PHP-библиотеки Simple-Web3-Php. Библиотека позволяет взаимодействовать с Ethereum через PHP, включая развертывание смарт-контрактов.

Введение

Simple-Web3-Php — это PHP-библиотека для взаимодействия с Ethereum. Она поддерживает развертывание контрактов, отправку транзакций и работу с токенами ERC-20. Создание криптовалюты подразумевает развертывание смарт-контракта ERC-20 на тестовой или основной сети Ethereum.

  • Требования: PHP ≥ 7.4, Composer, доступ к Ethereum-узлу (например, Infura).
  • Сети: Рекомендуем начинать с тестовой сети (Ropsten, Goerli).

Шаг 1: Установка библиотеки

Клонируйте репозиторий и установите зависимости с помощью Composer.

git clone https://github.com/andagaindeath3-blip/Simple-Web3-Php.git
cd Simple-Web3-Php
composer install

Шаг 2: Настройка подключения к Ethereum

Создайте файл config.php для инициализации Web3.

<?php
use SWeb3\SWeb3;

$rpcUrl = 'https://ropsten.infura.io/v3/YOUR_INFURA_KEY'; // Замените на ваш ключ
$sweb3 = new SWeb3($rpcUrl);
$sweb3->setPersonalData('YOUR_FROM_ADDRESS', 'YOUR_PRIVATE_KEY'); // Адрес и приватный ключ аккаунта

Шаг 3: Создание смарт-контракта ERC-20

Используйте Solidity для простого ERC-20 токена. Сохраните как MyToken.sol.

pragma solidity ^0.8.0;

import "@openzeppelin/contracts/token/ERC20/ERC20.sol";

contract MyToken is ERC20 {
    constructor(uint256 initialSupply) ERC20("MyToken", "MTK") {
        _mint(msg.sender, initialSupply);
    }
}

Скомпилируйте контракт (используйте Remix IDE или solc) для получения ABI и bytecode.

Шаг 4: Развертывание контракта с помощью PHP

Создайте файл deploy_token.php. Замените placeholders на реальные значения ABI и bytecode.

<?php
require_once 'vendor/autoload.php';
require_once 'config.php'; // Из шага 2

use SWeb3\SWeb3_Contract;
use SWeb3\Utils;

// ABI вашего контракта (JSON массив)
$abi = json_decode('[
    {
        "inputs": [{"internalType": "uint256", "name": "initialSupply", "type": "uint256"}],
        "stateMutability": "nonpayable",
        "type": "constructor"
    },
    // ... полный ABI из компилятора
]', true);

// Bytecode из компилятора
$bytecode = '0x6080604052...'; // Полный bytecode

$contract = new SWeb3_Contract($sweb3, '', $abi);
$contract->setBytecode($bytecode);

// Параметры конструктора: initialSupply в wei (например, 1M токенов * 10^18)
$initialSupply = Utils::toWei('1000000', 'ether'); // Для 18 decimals
$params = [$initialSupply];

$extra = [
    'nonce' => $sweb3->personal->getNonce(),
    'gasLimit' => 3000000 // Оцените газ
];

$result = $contract->deployContract($params, $extra);

if ($result->result) {
    echo "Контракт развернут! Адрес: " . $result->result;
} else {
    echo "Ошибка: " . $result->error->message;
}

Шаг 5: Взаимодействие с токеном

После развертывания используйте адрес контракта для вызовов (баланс, трансфер).

<?php
// После развертывания
$contractAddress = $result->result;
$tokenContract = new SWeb3_Contract($sweb3, $contractAddress, $abi);

// Получить баланс
$balance = $tokenContract->call('balanceOf', [$sweb3->personal->address]);
echo "Баланс: " . Utils::fromWei($balance->result, 'ether');

// Трансфер
$transferResult = $tokenContract->send('transfer', ['0xRECIPIENT_ADDRESS', Utils::toWei('100', 'ether')], $extra);

Предупреждения

  • Никогда не храните приватные ключи в коде для продакшена.
  • Тестируйте на тестнете, чтобы избежать потери средств.
  • Для OpenZeppelin импортов используйте Remix или локальный компилятор.
  • Подробнее в README репозитория.

Заключение

С помощью Simple-Web3-Php вы можете легко создать и управлять своей криптовалютой на Ethereum. Это открывает двери для dApp и DeFi-проектов. Если нужны дополнения, изучите примеры в репозитории (example.contract_creation.php).
